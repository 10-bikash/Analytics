This repository contains the end-to-end Data Analyst submission for the PEI technical assessment. The task covers source data profiling, data quality checks, star schema design, a data engineering story with QA test cases, and SQL queries to answer five business reporting requirements.

Source profiling — document tables, columns, data types, and descriptions
Data quality checks — verify accuracy, completeness, and reliability of source data
Proposed DE layer — define table structures with data types and constraints
Data model — ER diagram and star schema design
SQL queries — answer five business reporting requirements using available data
